## Fork 后发布自己的版本

Fork 的仓库首页也会显示上面的原站试玩入口。要让你的副本拥有自己的游玩地址，用浏览器打开你的 Fork 并设置 GitHub Pages。

1. 打开 **Settings → Pages**。
2. 把 **Source** 设为 **Deploy from a branch**。
3. 选择 **`main`** 分支和 **`/ (root)`** 目录，然后点 **Save**。
4. 部署完成后，点 **Visit site** 打开你的版本。

如果你想让来访者从你的 Fork 首页直接打开你的版本，把上面的试玩链接更新为自己的 Pages 地址。
